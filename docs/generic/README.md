# Generic Nitro formats

> **Project:** Mario Kart DS Modding Trove · **Licence:** MIT

Types in this group describe Nitro resources that are not specific to Mario
Kart DS. They live under `include/nitro/` and their emitters under
`tools/ctables/generic/`.

| Document | Covers |
|---|---|
| [nitro.md](nitro.md) | NDS header, FNT/FAT, overlays, BLZ, NARC/CARC |
| [formats-g2d.md](formats-g2d.md) | NCGR, NCLR, NSCR, NCER, NFTR, NANR |
| [formats-g3d.md](formats-g3d.md) | NSBMD, NSBTX, NSBCA, NSBTP, NSBTA, NSBMA |
| [formats-audio.md](formats-audio.md) | SDAT, SSEQ, SSAR, SBNK, SWAR, SWAV |

Headers: `include/nitro/{nds,narc,blz,bmg,dwc}.h`, `include/nitro/g2d/`,
`include/nitro/g3d/`, `include/nitro/snd/`.
