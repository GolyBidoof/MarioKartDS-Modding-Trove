# MKDS file formats

> **Project:** Mario Kart DS Modding Trove · **Licence:** MIT

Types in this group describe a concrete stock file or save block. They live
under `include/nitro/mkds/` and their emitters under `tools/ctables/mkds/`.

| Document | Covers |
|---|---|
| [formats-mkds-course.md](formats-mkds-course.md) | NKM, KCL, SPA |
| [formats-mkds-race.md](formats-mkds-race.md) | rank, item, kart, mission, object and small tables |
| [formats-mkds-ui.md](formats-mkds-ui.md) | JNLib lists, keyboard, emblem layout, banner font |
| [formats-save.md](formats-save.md) | `.sav` blocks and envelopes |
| [save-file-map.md](save-file-map.md) | byte-by-byte save map and editable representation |
| [formats-ids.md](formats-ids.md) | stage/mission/race id spaces |
| [bmg.md](bmg.md) | MKDS BMG banks |

Headers: `include/nitro/mkds/{common,course,save,race,ui,files,rom,bmg}/`.
